# Checklist de revisão do case

Use esta lista antes de compartilhar o case em uma página de portfólio, currículo ou publicação profissional.

## Precisão

- [x] O case está classificado como `Em evolução`.
- [x] A arquitetura descreve padrões técnicos sem prometer execução em produção.
- [x] A fila explicita idempotência, bloqueio, tentativas e estados terminais.
- [x] Os cenários de teste registram comportamento esperado, não métricas não comprovadas.

## Segurança

- [x] Não há marca, pessoa, portal, cidade, ambiente ou identificador de cliente.
- [x] Não há aplicativo, fluxo, robô, planilha, documento ou captura de tela original.
- [x] Os dados e referências de armazenamento são sintéticos.
- [x] Extensões de arquivos sensíveis são ignoradas pelo Git.

## Publicação

- [x] Links internos foram revisados.
- [x] O schema e a amostra sintética foram validados localmente.
- [x] O card de portfólio deve apontar para este repositório e manter a limitação explícita.
